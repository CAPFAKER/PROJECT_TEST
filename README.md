# Comissões dos Bolões

App simples para calcular as comissões das funcionárias e da gerente de uma lotérica a partir das vendas de cotas de bolões.

## O que faz

- Cadastro de funcionárias com percentual, meta (em R$ ou cotas) e bônus
- Comissão por faixa de meta, paga sobre a tarifa (40% da meta: 15%, 60%: 23%, 100%: 28%, tudo editável)
- Gerente pode também vender: recebe a comissão das próprias vendas e um percentual sobre as vendas das outras
- Bolões com valor total da cota, tarifa e valor do bolão calculado (cota menos tarifa)
- Lançamento de vendas com data, para rastrear
- Fechamento por período com envio do extrato pelo WhatsApp
- Botão Salvar e backup em Ajustes

## Como usar no celular

1. Abra https://capfaker.github.io/PROJECT_TEST/ no Safari (iPhone) ou no Chrome (Android)
2. Adicione à tela inicial
3. Os dados ficam salvos no próprio aparelho. Faça backup em Ajustes com frequência

## Arquivos

- `index.html`: o app completo (um único arquivo, funciona sem servidor)
- `planilhas/Comissoes_Boloes_Numbers.xlsx`: versão para o Numbers (iPhone)
- `planilhas/Comissoes_Boloes_Google.xlsx`: versão para o Planilhas Google
